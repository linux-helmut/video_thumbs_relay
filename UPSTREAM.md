# Upstream project and modifications

This project is based on the worker from:

- Original repository: https://github.com/silversong88/video_thumbs_relay
- Upstream application: Video Thumbnail Relay for Nextcloud

This repository focuses on building and distributing a Docker image for the worker.

Local modifications include configurable scan paths through the `SCAN_PATHS` environment variable.
